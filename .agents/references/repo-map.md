# Reference: Repo Map

## Core Paths
- `src/presentation/screens/`: pantallas y flows principales
- `src/presentation/components/`: componentes UI y dashboards
- `src/core/entities/`: entidades del dominio
- `src/store/`: store y slices Redux
- `src/store/slices/`: slices por dominio
- `src/hooks/`: hooks compartidos (`useAuth`, `useForm`, hooks tipados)
- `src/firebase/`: config e integraciones Firebase
- `src/index.css`: estilos globales (Tailwind)
- `public/`: assets estaticos
